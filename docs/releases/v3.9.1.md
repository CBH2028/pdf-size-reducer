# v3.9.1 — Reliable cancellation and smoother preview handling

This update improves the everyday merge-and-compress workflow when a task is cancelled, a source file changes, or a background worker stops responding.

- **Safe final output handling:** background writers create temporary candidates; the desktop application checks completion, source state, size, and cancellation before installing the result. Interrupted tasks preserve existing destinations.
- **Bounded cancellation:** writers get a three-second cooperative grace period. On Windows, unresponsive workers and their native descendants are then terminated together.
- **Cancellable high-resolution previews:** rendering runs in its own process, closing a preview cancels its job, and opening the same Figure again reuses the existing window.
- **Stale selection detection:** ordinary source-file edits after scanning or during processing are detected, with a reload request before old Figure selections can be committed to new content.
- **Clearer task progress:** desktop progress stays monotonic and reaches 100% after output installation. Scanner and thumbnail startup failures report errors and release started processes.

The matched protocol-3 Rust/C++ worker remains included. Compression quality settings and the native Figure planner remain available.

The packaged Windows executable passed worker discovery and the extended smoke test covering guarded merging, lossless compression, high-resolution preview, native Figure planning, and cancellation just before final output installation.

**80 Python regression tests passed.** A 97.92 MiB / 48-page UI check loaded all 48 assets and thumbnails in 5.905 seconds with a maximum measured event-loop gap of 34.02 ms; scan cancellation also completed cleanly. These are UI checks, including startup and interface transitions, rather than a new compression speedup comparison.

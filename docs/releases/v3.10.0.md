# v3.10.0 - Edit PDF text, match document styling, and delete pages

This release adds a local PDF editor alongside the existing merge-and-compress workflow.

## New features

- **Automatic regions:** detect paragraphs, separate distant text columns, and identify image areas. Click a text region to edit it, or draw a new text box.
- **Matched text styling:** inherit font size, color, line spacing and alignment from nearby text. Reuse embedded fonts when they include the new characters; clearly report font substitutions when exact reuse is unavailable.
- **Real PDF preview:** preview and save use the same text layout. Overflow and neighboring-text collisions are reported instead of silently shrinking text, clipping content or covering other paragraphs.
- **Page deletion:** delete/restore the current page or enter original page ranges such as `2, 4-6`. Original numbering remains stable while editing. Undo/redo covers both text changes and page deletion; at least one page must remain.
- **Edit, save, then compress:** save an independent edited PDF or send the result directly to the accelerated compression workspace. Text stays searchable and pages are not rasterized on export.
- **Safe task handling:** analysis, previews and saving run in cancellable processes. Source changes and last-moment cancellation are checked before installing the output; original PDFs remain untouched.

## Scope and verification

This is primarily a horizontal-text editor, not OCR, structured table editing or full-document reflow. Scanned-image text cannot be directly replaced. Mixed-style regions use their dominant style, and font fallbacks need visual review. Signature-field documents, unsafe overlaps, unsupported text orientations and pre-existing redaction annotations are protected against unintended changes. Page deletion removes links targeting deleted pages and disables their bookmarks.

**135 Python regression tests passed.** The application includes an `--editor-self-test` covering the real Qt interface, isolated previews and saving, bilingual text, page deletion and compression handoff. The existing guarded compression and merge workflow remains available.

The packaged Windows executable passed all three checks: native-worker discovery, the existing guarded workflow self-test, and the new editor self-test (all exit code 0).

The matched protocol-3 Rust/C++ worker is unchanged. Editing uses isolated PyMuPDF workers; this release does not claim an additional compression speedup or an OS security sandbox. Source installations require PyMuPDF 1.26 or newer.

Downloads: `PDF_Size_Reducer.exe`, `PDF_Fast_Worker_Windows_x64.zip`, and `SHA256SUMS.txt`.

All PDF processing stays local. See the [editing guide](https://github.com/CBH2028/pdf-size-reducer/blob/v3.10.0/docs/EDITING.md) for controls and limitations.

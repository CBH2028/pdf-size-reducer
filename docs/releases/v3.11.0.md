# v3.11.0 - Focused PDF merging and compression

PDF Size Reducer now focuses on two jobs: combining PDFs and reducing their size. The text editor, automatic text-region editing, text insertion, font-matching controls and page deletion have been removed. Compression's Figure discovery, visual selection and preview remain available. Existing documents and historical releases are unchanged.

## A more convenient merge workflow

- **Drop files straight into the queue.** See numbered entries, each file's page count, size and folder, plus page and size totals. Duplicate, invalid and over-limit inputs are reported. Double-click an entry to inspect it in your default PDF reader.
- **Arrange multiple files together.** Ctrl/Shift-select entries and move them as a group using the buttons or Alt+Up/Down. Natural filename sorting orders `1, 2, 10` correctly. Undo restores the queue after adding, removing, clearing or reordering entries; removing an entry never deletes its source file.
- **Save without losing your setup.** A suggested filename avoids existing files and can be edited directly. Custom names survive queue changes. Declining an overwrite leaves the queue open so you can change the destination.
- **Choose what happens next.** Select merge-only to save a combined PDF, or continue to the compression workspace to preview Figures and set an MB/KB target. Compression saves a separate result and retains the merged PDF.
- **Reuse the loaded PDF.** Opening the merge dialog includes the current workspace file. An explicit multi-file drop uses only that batch. Output cannot overwrite an input or the active workspace PDF.

## Reliability and verification

Basic page inspection runs in a cancellable background process. Unreadable and password-protected inputs are flagged before merging; changed files can be rechecked. The writer checks the recorded source states again before processing, and the existing parent-owned final installation protects against cancellation and ordinary source-file changes. Limits remain 100 PDFs, 4 GiB per file and 16 GiB in total. Metadata inspection is not a full document validation or an OS security sandbox.

**114 Python regression tests passed**, comprising 80 existing merge/compression/lifecycle tests and 34 new queue/preflight tests. The Windows executable passed native-worker discovery, the new merge-UI self-test, and the existing merge/compression/preview/native-planner/cancellation workflow self-test, all with exit code 0.

The matched protocol-3 Rust/C++ worker is unchanged. This release does not claim an additional compression speedup. Form-containing PDFs still use the compatibility merger to preserve editable fields. Document-level attachments, PDF portfolios, digital signatures and named destinations are not guaranteed to survive merging.

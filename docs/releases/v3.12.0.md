# v3.12.0 - Visual PDF page composition

Build a new PDF from pages across multiple documents using a fully visual, three-column workspace.

## Main PDF · Composition tree · Material library

- **Left:** browse the main PDF or switch to a live preview of the assembled output. Selecting a tree page reveals its output position; double-click any page for a larger zoomable preview.
- **Middle:** arrange a nested composition tree. Insert pages before or after a selected page, drop them into a group, create and rename branches, and move pages or groups between branches. Output follows the tree's depth-first order, and group names become PDF bookmarks.
- **Right:** add multiple material PDFs, keep adding more, search filenames, and browse each document's page thumbnails. Drag selected pages or whole PDFs into the tree. The material library is no longer limited to 100 files.

Ctrl/Shift selection, typed page ranges, multiple-node movement and undo/redo are supported. Removing a tree node only changes the new output plan; source files stay untouched. Declining an overwrite keeps the workspace open. Save the composition on its own or continue directly to the existing compression workspace.

The quick whole-document merger remains available separately. Text editing and text insertion have not been reintroduced.

## Preservation and safety

Selected pages are copied as PDF content, not rasterized. Searchable text, page geometry, rotation, ordinary annotations and supported editable form fields are retained. Internal links are remapped to included pages; links to omitted pages are removed. Repeated source pages use the first output occurrence as an internal-link target. The composition tree supplies the output bookmarks.

Source states are checked before processing and final output installation. Inspection, rendering and writing use cancellable processes, and the parent owns final installation. Explicit GUI-thread receivers keep background callbacks from manipulating widgets or timers in a worker thread.

The library uses batched inspection and on-demand, paginated thumbnail rendering. Resource limits still apply: 20,000 output pages, 12 tree levels, 4 GiB per source and 16 GiB across sources actually used. Document-level attachments, portfolios, signatures, named destinations and accessibility structure are not guaranteed to survive composition. See the [composition guide](https://github.com/CBH2028/pdf-size-reducer/blob/v3.12.0/docs/COMPOSING.md).

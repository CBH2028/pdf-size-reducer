# v3.14.0 - Animated startup and full-quality graphics export

PDF Size Reducer v3.14.0 provides immediate animated launch feedback and adds a local export workflow for graphics already inside a PDF.

## No more blank launch interval

- A lightweight bootloader splash appears while the one-file Windows executable is unpacking and changes its status as components load.
- It hands off to a native Qt animation with a pulsing halo, rotating arc, moving progress light and live initialization text.
- The main workspace replaces the animation only after it is ready to interact with. Background PDF workers do not create duplicate splash windows.

## What is new

- Check the exact Figure/image cards you need, then click **Export selected high-resolution graphics…**. Selecting N cards exports exactly N items; no selection disables the action. Choose SVG, PNG, PDF, or any format combination, then select a parent folder. The app creates a non-conflicting directory containing only those selected items and formats.
- Each detected complete Figure can be exported as self-contained SVG, up-to-600-DPI PNG, and a one-graphic-per-page PDF. Existing PDF paths stay vector data in SVG/PDF instead of being flattened, while raster portions inside a mixed Figure retain their source pixels.
- Each standalone bitmap retains its original pixels in every selected format. SVG and PDF act as self-contained containers rather than applying vector tracing.
- `manifest.json` records the requested formats, source page, dimensions, output files and preservation mode for every item.

## Truthful vector handling

The release does not pretend that a photograph can become a genuine vector without changing it. Native vector plots remain vector. Native bitmaps remain original-resolution bitmaps embedded in SVG, and the manifest identifies them accordingly. No AI tracing, cloud upload or resampling is performed.

## Safety and verification

Export runs in an isolated, cancellable process. A complete directory is staged first and installed only after the source PDF is rechecked; cancellation, a source change, a crash or a destination-name collision leaves no partial final directory. The source PDF is never modified.

All 237 Python tests pass. The new tests cover exact selected-item export, empty-selection rejection, changing animation frames, clean main-window handoff, deterministic early-splash asset, bootloader configuration, checkbox selection, per-format exclusivity, PDF vector/text retention, SVG readability, preserved vector paths and mixed image layers, exact bitmap dimensions, manifest privacy, stale-source rejection, cancellation, directory collisions, source changes during export and parent-owned atomic installation. The packaged Windows executable passes all seven checks, including direct verification that the bootloader splash is alive and the Qt animation changes frames.

The existing PDF composition, accelerated compression and matched protocol-3 Rust/C++ worker remain unchanged. This release does not claim a new compression-speed increase.

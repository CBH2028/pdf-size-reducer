# v3.9.0 — Faster scanning and safer PDF workflows

This release improves document preservation, background processing, and failure recovery across the merge-and-compress workflow.

## What is improved

- **1.60× faster asset scanning** on the fixed 97.92 MiB / 48-page test PDF: median time dropped from **5.471 to 3.421 seconds**, with identical detected assets.
- **Editable PDF forms survive merging.** AcroForm documents automatically use the form-aware compatibility merger; the native backend rejects unsupported forms instead of dropping fields.
- **Links remain correctly positioned on rotated pages**, including overlapping links with different targets.
- **Compression runs in its own background process**, with cooperative cancellation, crash reporting, and shared merge/compression cleanup.
- Invalid or password-protected files cannot bypass validation just because they already fit the target size.
- Native-worker launch and handshake failures recover cleanly; merge progress no longer moves backwards during fallback.
- Lossless optimization runs before candidate scanning, and explicitly unselected content avoids unnecessary parsing.

## Verification and performance scope

**63 Python regression tests and 5 Rust unit tests passed.** The packaged executable passed native-worker discovery and a headless `--workflow-self-test` for guarded merging followed by lossless compression.

Three alternating runs per version confirmed matching asset records, preserved merged text and 800 links, and identical compressed 72-DPI page renders. Merge and six-page bitmap compression times were essentially unchanged. That compression case did not use the native Figure planner.

The earlier **17.889× compression improvement** remains the historical v3.5-versus-v3.3.1 Automatica result; this release does not claim another 17× improvement. See the repository's benchmark results for the exact scope and per-run data.

## Downloads

- `PDF_Size_Reducer.exe`: portable Windows application with the matching Rust-guarded native worker.
- `PDF_Fast_Worker_Windows_x64.zip`: standalone guarded worker bundle.
- `SHA256SUMS.txt`: download integrity checksums.

All PDF processing remains local. Password-protected inputs must be decrypted first. Digital signatures, document-level attachments, portfolios, and named destinations are not guaranteed to survive page merging. Complex PowerPoint vector figures can still require visual review or exclusion from compression.

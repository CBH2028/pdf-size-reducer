# v3.13.0 - Drag, arrange, save

The default PDF composer is now a simple two-pane workspace. Drag the pages you need from the material pane on the right into the result on the left, drag result pages to reorder them, and save the new PDF.

## A simpler everyday workflow

- Only three buttons remain visible: **Add PDF**, **Save PDF** and **Advanced composition**.
- Load multiple material PDFs and switch between them with a compact document selector.
- Drop pages at the colored insertion marker. Ctrl/Shift multi-selection, continuous scrolling and drag-edge scrolling work with longer documents.
- Double-click to zoom. Hover **×** or Delete omits a page from the result; Ctrl+Z and Ctrl+Shift+Z/Ctrl+Y undo and redo changes. Source PDFs stay unchanged.
- Save through a standard file dialog. Cancelling retains the arrangement; the default save flow offers the existing compression workspace afterward.

## Advanced tools, available when needed

The composition tree, nested groups and bookmarks, page ranges, insertion buttons, source rechecking, save-only choice and whole-document merge now live under **Advanced composition**. There is no separate whole-merge button on the main window.

Both modes use the same plan and undo history. Switching modes preserves groups, page identities, ordering and save settings. Cancelling the optional whole-document queue returns to the unchanged page plan; completing that queue exports its entire documents instead.

## Preservation and performance

The composer still copies original PDF pages rather than rasterizing them. Existing source-state checks, overwrite protection, process isolation and cancellation remain in place. Simple-mode thumbnails load only for visible pages and use a bounded cache. The existing limits and document-preservation caveats are described in the composition guide.

The matched protocol-3 Rust/C++ accelerator is unchanged. This release simplifies interaction; it does not claim a new compression speedup or restore text editing.

## Verification

All **209 Python regression tests passed**, including 31 new simple-mode cases. The packaged Windows executable passed all five checks: native-worker discovery, whole-merge UI, advanced composer, simple drag-and-drop composer and the existing compression workflow (exit code 0 for each).
